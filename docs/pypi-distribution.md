## Historical exploration and retirement

The #58 sandbox prototype established that a wheel could carry canonical instructions, roles, dotfiles, Python evidence/runtime helpers, browser resources and FSL notices without configuring a project at package installation. It delegated explicit configuration to the shared #53 installer. The maintained terminal-first CLI from #66 replaced that sandbox architecture; it supports fresh setup and identical repeats, preserves project policy and runtime choices, and refuses implicit migrations.

Issue #88 retired `experiments/pypi-installer`. Its [complete historical source](https://github.com/spring-labs-inc/FlightCheck/tree/08e7e15fca019ff6d00307fbaf31ebefebccc86b/experiments/pypi-installer), [original guide](https://github.com/spring-labs-inc/FlightCheck/blob/08e7e15fca019ff6d00307fbaf31ebefebccc86b/experiments/pypi-installer/README.md), [inventory](https://github.com/spring-labs-inc/FlightCheck/blob/08e7e15fca019ff6d00307fbaf31ebefebccc86b/experiments/pypi-installer/assets.json) and [exploration narrative](https://github.com/spring-labs-inc/FlightCheck/blob/08e7e15fca019ff6d00307fbaf31ebefebccc86b/docs/pypi-distribution.md) remain in Git history. Earlier name-availability observations, unpublished-distribution labels, experimental commands and planning conclusions there are historical; they do not describe the published a2 channel.

Before removal, all eight prototype tests and all files were inventoried. ## Retained qualification and release limits

The application minimum remains Python 3.9 on POSIX; a `py3-none-any` wheel is not Windows qualification. Native Windows and cloud environments remain unqualified. The bounded four-interface native observations and owner-accepted manual prepare/check/footer limitation remain in the [qualification report](claude-trial-report.md#accepted-native-app-scope); source-path consolidation does not reopen that campaign or promise automatic interception.

A newly versioned release needs clean reviewed source/tag, exact wheel/sdist/source/manifest identity, preserved [FSL-1.1-MIT notices](../LICENSE), an immutable reviewed Actions artifact, and separate actual exact-wheel local/real SSH card startup, recovery and browser rendering. Worker HTTP success is not browser reachability or rendering. Retained earlier native observations do not qualify changed release bytes. Refer to the canonical guide and current release issues for the bounded acceptance; no new four-client campaign is implied.

Public upload, matching GitHub assets and Homebrew require their separate owner authorization. Keep protected human review and publication disabled during preparation. Reuse the same retained artifact bytes across authorized channels; do not rebuild, replace a published version, move its tag or reset historical license/publication terms. Installing, replacing or uninstalling the global CLI must not silently change a configured project's workflow, runtime, dependencies or retained private evidence.
